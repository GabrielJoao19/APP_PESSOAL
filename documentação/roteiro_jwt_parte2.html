Roteiro JWT: O Porteiro e os Cadeados

Como trancar as suas rotas e bloquear usuários sem o Token

1

Criando o Scanner (Strategy)

Crie um arquivo chamado jwt.strategy.ts dentro da pasta src/auth/. Esse arquivo é o "leitor de código de barras". Ele ensina o NestJS a extrair o token do cabeçalho Bearer e a usar a Palavra Secreta para validar a assinatura.

import { ExtractJwt, Strategy } from 'passport-jwt';
import { PassportStrategy } from '@nestjs/passport';
import { Injectable } from '@nestjs/common';

@Injectable()
export class JwtStrategy extends PassportStrategy(Strategy) {
  constructor() {
    super({
      // Ensina a pegar o token do lugar certo (Header > Bearer)
      jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(),
      // Rejeita tokens expirados
      ignoreExpiration: false,
      // A mesma senha secreta do .env!
      secretOrKey: process.env.JWT_SECRET, 
    });
  }

  // Se o token for verdadeiro e válido, ele cai nessa função
  async validate(payload: any) {
    // O que você retornar aqui será pendurado no objeto da requisição (req.user)
    return { usuarioId: payload.sub, email: payload.email };
  }
}
2

Criando o Porteiro (Guard)

Crie um arquivo chamado jwt-auth.guard.ts na mesma pasta src/auth/. Esse arquivo é muito curto, ele é literalmente o "segurança fortão" que fica na porta interceptando a requisição.

import { Injectable } from '@nestjs/common';
import { AuthGuard } from '@nestjs/passport';

@Injectable()
export class JwtAuthGuard extends AuthGuard('jwt') {}
3

Registrando no AuthModule

Abra o seu auth.module.ts. O "RH" precisa saber que você contratou um novo segurança (a Strategy). Adicione a classe JwtStrategy na lista de providers.

// ... imports normais ...
import { JwtStrategy } from './jwt.strategy.js'; // Importe a Strategy!

@Module({
  imports: [ /* ... seus imports ... */ ],
  controllers: [AuthController],
  providers: [AuthService, JwtStrategy], // <-- Coloque a JwtStrategy AQUI!
})
export class AuthModule {}
4

Trancando os Controllers e Usando o ID

Agora a mágica acontece. Escolha um Controller (ex: financas.controller.ts). Vamos colocar o cadeado no topo dele e mostrar como você pega o ID do usuário que acabou de passar pela porta!

import { Controller, Post, Body, UseGuards, Request } from '@nestjs/common';
import { JwtAuthGuard } from '../auth/jwt-auth.guard.js';

@Controller('financas')
@UseGuards(JwtAuthGuard) // <-- ESSE É O CADEADO GERAL DA PASTA FINANÇAS!
export class FinancasController {
  
  @Post()
  criarGasto(@Request() req, @Body() dados: QualquerDto) {
    // 💡 O porteiro validou o JWT e "pendurou" os dados do usuário no objeto req!
    const idDoUsuarioLogado = req.user.usuarioId;
    
    // Agora você pode passar esse ID para o seu Service salvar no banco certinho
    return this.financasService.criar(idDoUsuarioLogado, dados);
  }
}
